# ShopVote – Online Voting System

## Project Overview
ShopVote is a Java-based online voting and poll management system developed using JSP, Servlets, HTML, CSS, Maven, and Apache Tomcat 11. The application allows users to register, log in, participate in multiple-choice polls, and view voting results.

## Features
- User Registration and Login
- Secure Password Handling
- Four Multiple-Choice Polls
- Vote Submission
- Results with Vote Counts and Percentages
- Logout Functionality
- Simple and User-Friendly Interface

## Technologies Used
- **Frontend:** HTML, CSS, JSP
- **Backend:** Java Servlets
- **Server:** Apache Tomcat 11
- **Build Tool:** Maven
- **IDE:** Eclipse IDE
- **Java Version:** Java 17 or later

## Poll Categories
1. Favourite Social Media App
2. Favourite Shopping App
3. Favourite Game
4. Favourite Programming Language

## How to Run the Project in Eclipse
1. Install Java JDK 17 or later and Eclipse IDE.
2. Install or configure Apache Tomcat 11 in Eclipse.
3. Import the project into Eclipse as an existing Maven project.
4. Wait for Maven dependencies to download.
5. Configure Tomcat 11 as the project server.
6. Right-click the project and select **Run As → Run on Server**.
7. Open the local URL provided by Eclipse in your browser.

## Project Purpose
The purpose of ShopVote is to provide a simple platform for conducting online polls and displaying voting results. It demonstrates the use of Java web technologies, session handling, form processing, and server-side application development.
